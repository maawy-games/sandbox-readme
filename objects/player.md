## Player Object

### Functions

* `set_accepts_input(accepts: bool)` - accept or reject keyboard input for default behavior.
* `set_allow_jump(allow: bool)` - set can jump by pressing space bar or using `jump()`.
* `move_left()` - apply force to move left.
* `move_right()` - apply force to move right.
* `jump()` - apply jump force. Can only be used when `allow_jump` is set.
* `get_color()` - can be used to get the color of the player object **(pro version)**.
