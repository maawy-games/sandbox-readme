## Character Object

### Functions

* `climb()` - sets the player to have climb animation.
* `duck()` - sets the player to have duck animation.
* `hit()` - sets the player to have hit animation.
* `face_front()` - sets the player to have face_front animation.
* `set_default_animations()` - resets to the default automated animations instead.
* `get_color()` - Gets the character color **(pro version)**.
